# Architecture Principles

Foundational principles that guide architecture and design decisions across enterprise systems.

## Core Principles

- **[API-Led Architecture](api-led.md)** – APIs as first-class integration mechanism
- **[Cloud-Native Design](cloud-native.md)** – Built for cloud, scalable, resilient
- **[Microservices Architecture](microservices.md)** – Bounded contexts, independent scaling, resilience
- **[Event-Driven Architecture](event-driven.md)** – Async communication, eventual consistency
- **[Domain-Driven Design](domain-driven.md)** – Business domains shape architecture

## Quality Attributes

- **[Scalability](scalability.md)** – Horizontal scaling, stateless services, distributed systems
- **[Availability](availability.md)** – Fault tolerance, redundancy, disaster recovery
- **[Security](security.md)** – Defense in depth, encryption, identity, compliance
- **[Performance](performance.md)** – Latency optimization, throughput, resource efficiency
- **[Maintainability](maintainability.md)** – Code clarity, documentation, knowledge transfer

## Architectural Patterns

- **[Strangler Pattern](../patterns/strangler.md)** – Gradual modernization of legacy systems
- **[CQRS](../patterns/cqrs.md)** – Command Query Responsibility Segregation
- **[Event Sourcing](../patterns/event-sourcing.md)** – Event-based state management
- **[Saga Pattern](../patterns/saga.md)** – Distributed transactions across services
