# Metadata Usage Guidelines

## For Development Planning

Use `phase` and `expected_case_study_length` to track development calendar and resource allocation.

Use `client`, `employer`, `domain`, and `technologies` to identify related projects and build thematic portfolio sections.

## For Interview Preparation

Use `interview_priority`, `interview_focus`, and `quantified_outcomes` to prepare STAR stories and talking points.

## For Portfolio Presentation

Use `visibility` to determine which projects are suitable for public portfolio vs. anonymized narrative.
